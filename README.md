# 보름 근육검사

기능회복운동센터 보름의 근육 활성화 검사 도구입니다. 서버 없이 GitHub Pages 같은 정적 호스팅에서 그대로 동작합니다.

## 주소

| 페이지 | 누가 쓰나 | 하는 일 |
|---|---|---|
| `trainer.html` | 트레이너 (비밀번호) | 통증 부위 선택 → `[왼쪽 · 근육 · 오른쪽]` 활성화 체크 → 결과 → 회원에게 링크/QR 보내기, 운동 후 재검사 |
| `index.html` | 회원 | 기본 화면은 방문 전 자가진단. 트레이너가 보낸 `index.html#r=…` 링크로 열면 검사 결과 화면 |

## 데이터가 저장되는 방식

- 검사 결과는 **링크 자체에 담깁니다** (`#r=` 뒤 코드). 서버나 DB에 저장되지 않습니다.
- 링크에 들어가는 것: 이름, 날짜, 통증 부위, 꺼진 근육(좌/우), 통증 강도, 현재 단계, 재검사 결과.
- 링크에 들어가지 않는 것: 반사점 이미지, 트레이너 메모.
- 최근 검사 목록과 진행 중인 검사는 트레이너 기기의 브라우저에만 저장됩니다.

## 반사점 이미지 보호

`assets/reflex.enc`는 AES-GCM으로 암호화되어 있어 저장소가 공개여도 비밀번호 없이는 볼 수 없습니다. 비밀번호를 바꾸려면 원본 이미지로 다시 암호화해야 합니다.

## 파일

- `assets/data.js`: 근육 목록·기능·검사 순서·신체 지도 경로 (자동 생성). 근육 순서는 공유 코드 인코딩 순서이므로 **새 근육은 맨 뒤에만 추가**해야 기존 링크가 깨지지 않습니다.
- `assets/common.js`, `assets/common.css`: 두 페이지가 같이 쓰는 로직과 스타일 (리플렛 컬러).
- `assets/body.png`: 사장님 신체 도해.
- `assets/qrcode.js`: QR 생성 (qrcode-generator, MIT, Kazuhiko Arase).
